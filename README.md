Expense Tracker

A command-line Python application for recording income and expenses and reviewing a simple financial summary. This is a beginner learning project for the CodeNova Python Programming Internship.

Features : 
Add income and expense transactions
View all transactions
Calculate total income, total expenses, and balance
Filter transactions by date
Filter transactions by category
Validate amounts and dates
Save transaction data in JSON format

Transaction Fields : 
Each transaction includes its type, amount, category, optional description, and date.

Requirements : 
Python 3
No third-party packages required

Run the Program : 
Open a terminal in this folder and run:
python main.py

On some systems, use python3 main.py.
The program requires interactive keyboard input. If a mobile code runner reports EOFError, use a console or execution mode that supports input prompts.

Data Storage : 
Transactions are saved in transactions.json in the program's current working directory. Keep this file to retain transaction history between runs. The example project is not a substitute for a secure financial application; do not store sensitive financial information in a public repository.

Example : 
If recorded income is 5000 and expenses are 1200 and 500, the balance is 3300.

Concepts Practised : 
Functions, lists, dictionaries, loops, conditionals, input validation, date handling, JSON, and file handling.
